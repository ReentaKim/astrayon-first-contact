15개 테스트는 자원·피해 계산, 중복 공격 100회, 중복 종료, 오래된 세션 콜백, 잘못된 액션 ID, 정지 상태, 순수 reducer, 20초 쇼트 구간, BFS 장애물/이동력, 이동 취소, 최소·최대 사거리 및 맵 복귀를 다룹니다. 브라우저 검증을 대체하는 테스트로 간주하지 않습니다.

## 실제 브라우저에서 확인한 동작

- 타이틀 → 도트 기체 선택 → 이동 가능 칸 표시 → 경로 이동 → 공격 → 무기 선택 → 전투 → 결과 → 맵 복귀.
- 빔 라이플과 블레이드 러시를 각각 **스킵 없이 20.00초**까지 진행. 사격/부스터·검격의 서로 다른 컷, 파일럿 컷인, 충돌, 피해 및 결과 표시 확인.
- 라이플 결과: 아군 HP 6,000, EN 80, 적 HP 7,800, 조준 +1.
- 러시 결과: 아군 HP 5,600, EN 100, 적 HP 7,400, 받은 피해 400.
- 인접 위치에서는 라이플 비활성/러시 활성, 3칸 거리에서는 라이플 활성/러시 비활성.
- 일시정지 상태에서 약 16초가 지나도 표시 시간이 0.20초로 유지. 재개 후 정상 완료. 충돌 시점에서도 정지·재개 및 실제 렌더링 확인.
- 라이플 스킵 결과가 정상 종료와 동일. 러시 **3회 연속 재시작·스킵**에서도 매번 피해 1,600 / EN 100 / 아군 HP 5,600. 세션 2, 3, 4로 분리됨. `qa/replay-check.json`.
- 전투 결과에서 맵으로 돌아온 뒤 위치와 HP/EN 유지, 적 HP 7,400 표시.
- Enter로 무기 확정, 기체에 Enter 후 ArrowRight로 다음 칸 포커스 이동 확인.
- 음소거·자막·효과 감소 버튼의 상태와 접근성 이름 확인. 효과 감소 시 맵 이동이 즉시 완료됨.
- 최종 프로덕션 페이지에서 수집한 warn/error 콘솔 목록은 빈 배열. `qa/browser-console.json`.

## 미검증·제한

- `/review` 검수 페이지는 빌드되었으나 Chrome의 `ERR_BLOCKED_BY_CLIENT`로 직접 진입이 막혀 브라우저 검증을 완료하지 못했습니다. 브라우저 보호 설정을 변경하지 않았습니다. 본편 `/`의 전투 검증은 정상 완료했습니다.
- Web Audio 코드와 사용자 입력 후 실행, 설정 상태는 확인했지만 실제 스피커 청취·음량 밸런스·지연 측정은 하지 않았습니다. 성우 녹음은 없습니다.
- 실제 모바일 기기의 터치·GPU, Safari/Firefox, 스크린리더, 전체 화면 권한 흐름, 탭 숨김 자동 정지, 자산 실패 강제 주입은 이번 브라우저 검사에서 다루지 않았습니다. 해당 대응 코드가 있는 것과 검증 완료는 구분합니다.
- fps/메모리 수치를 계측하지 않았으므로 60fps 또는 장시간 안정성을 보장하지 않습니다.
- 한 번의 교전 데모입니다. 적 턴 AI, 복수 유닛, 연속 턴, 캠페인, 전체 3분 시나리오는 포함하지 않습니다.
- 신규 원화는 포즈 전환과 카메라·효과로 움직입니다. 최종 연결 애니메이션, 전용 파일럿 컷인, 최종 음향은 [ASSET_REPLACEMENTS.md](ASSET_REPLACEMENTS.md)에 분리했습니다.
- 공개 배포는 하지 않았습니다. 검수용 서버는 작업 종료 시 정리하며, 다시 플레이할 때 `플레이.command`를 실행합니다.
