## 기하·시간 검증

- 검격은 각 관절을 동시에 보간하지 않습니다. 골반/하체가 먼저 힘을 풀고 몸통·팔·검이 뒤따르는 것을 수치로 검사합니다.
- 본 공격 후 적 기체가 120px 이상 밀리며, 반격 후 아군도 70px 이상 밀립니다. 수치는 논리 전장 1600×900 기준입니다.
- 적의 15.50초 붕괴 자세에서 실제 골반은 회복 자세보다 약 26px 낮습니다. 무릎을 접고 다시 일어서는 동작을 연결했습니다.
- 기존 원화의 목·어깨·팔꿈치·손·골반·무릎 접합점은 연결된 상태를 유지합니다.
- 독립 검토에서 양 무기·표준/효과 감소를 20초 전체 1ms 간격으로 확인했습니다. 관절 이탈과 바닥 침투는 부동소수점 오차 범위 이내, 최대 루트 이동은 1ms당 약 1.72px였습니다. 실제 FPS 측정 결과를 뜻하지 않습니다.
- 칼날 접촉 거리: 첫 패링 4.21px, 본 공격 18.73px, 반격 9.41px. 라이플 총신과 빔 조준도 유지합니다.
- 시간 역행 탐색 후 같은 시점의 자세가 동일합니다. 잔광과 먼지는 저장된 이전 프레임을 누적하지 않고 장면 시간에서 다시 계산합니다.
- 충돌 파편은 실제 충돌 좌표에 남습니다. 피해 기체를 따라가는 연기와 구분합니다.
- 효과 감소에서는 잔광·접지 먼지와 접촉 정지를 생략합니다. 기존 제한된 카메라 연출을 유지하며 추가 강한 화면 흔들림·섬광은 넣지 않았습니다.

## 실제 브라우저 플레이

개발 서버 검수 후 종료하고 최종 `out/`을 제공하는 `http://127.0.0.1:4173/`에서 다시 확인했습니다.

1. **러시:** 시작 → 7열 4행까지 일반 이동 → 공격 → 블레이드 러시 → 20.00초 자연 종료 → 맵 복귀. 최종 아군 HP **5,600**, EN **100**, 적 HP **7,400**.
2. **라이플:** 작전 다시 시작 → 5열 4행 이동 → 공격 → 빔 라이플 → 20.00초 자연 종료. 최종 아군 HP **6,000**, EN **80**, 적 HP **7,800**, 조준 **+1**.
3. 두 무기의 사거리 잠금, 결과 수치와 러시 맵 복귀를 확인했습니다. 자동 스킵으로 자연 종료를 대체하지 않았습니다.
4. `/review`에서 12.85초부터 0.5× 재생 후 정지. 16.496초에서 0.5초 동안 시간이 유지되고 다음 프레임 버튼 후 16.512초로 진행하는 것을 확인했습니다.
5. 표준/효과 감소 전환, 13.50초 접촉 선택, 정확한 시간 입력을 확인했습니다. 12.70–16.70초의 49개 시점을 실제 브라우저에서 입력해 렌더러 캡처를 저장했습니다.
6. 이번 검사 탭의 console warn/error는 **0건**입니다. `qa/motion-v4/browser-console.json` 참조.

## 검증 범위와 소재 상태

- 이번 변경은 기존 SD 원화의 관절·전신 동작과 효과 개선입니다. 새 이미지를 만들거나 캐릭터 원화를 교체하지 않았습니다.
- 16개 부품을 연결한 실시간 관절 애니메이션입니다. 다른 카메라 각도, 원근 변화, 손으로 그린 연결 프레임, 파일럿 눈·입 프레임은 후속 제작 대상입니다.
- 합성 음향은 데모용입니다. 오디오 정지·재개 로직의 회귀 검사는 통과했지만 실제 스피커 청취, 음량 믹싱, 지연 측정, 성우 녹음은 이번 작업 범위에 없습니다.
- 데스크톱 브라우저에서 검수했습니다. 모바일 GPU·터치, 다른 브라우저 엔진, 스크린리더와 장시간 FPS 측정은 별도 확인이 필요합니다.
- 플레이용 4173 서버는 유지하고 검수용 4180 개발 서버는 종료했습니다. GitHub 소스 공개와 웹 서비스 배포는 별도 작업입니다.
