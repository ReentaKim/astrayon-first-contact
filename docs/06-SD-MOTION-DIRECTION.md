# SD 전투와 동작 개편

2026-10-16 린타의 추가 요청을 반영한다. 기존 01 문서의 풀 사이즈 기체 제안은 이번 전투 표현에 적용하지 않는다. 사용자가 첨부한 실제 슈퍼로봇대전 화면은 SD 비례, 선명한 셀 채색 스프라이트, 조종석 안에서 행동하는 파일럿의 표정과 프레이밍을 참고하는 자료다. 기존 게임의 캐릭터·UI·음악을 가져오는 요청으로 해석하지 않는다.

## 구현 기준

- 아스트레이온과 옵시디언의 색, 얼굴, 장갑, 바인더 정체성을 유지한 SD 기체로 전투 스프라이트를 새로 제작한다.
- 하나의 완성 그림을 평행 이동하는 연출을 교체한다. 어깨·팔꿈치·손목·골반·무릎의 부모/자식 관절을 사용하고 무기를 손 소켓에 연결한다.
- 사격은 무기를 들어 올림 → 조준 자세 → 총구에서 빔 발사 → 어깨/팔 반동 → 복귀가 읽혀야 한다.
- 근접 공격은 준비 자세 → 압축/추진 → 검 휘두르기 → 접촉 순간 멈춤 → 통과/피격 → 자세 회복이 읽혀야 한다.
- 총구와 칼날의 효과는 실제 무기의 좌표를 사용한다. 카메라 흔들림으로 관절 동작을 대신하지 않는다.
- 파일럿은 기존 포스터 크롭을 전용 조종석 액션 컷인으로 교체한다. 공격 표정, 열린 입, 조종간을 잡은 손과 몸의 기울기가 보인다. 라이벌의 밝은 갈색 머리와 가면의 해부학적 좌우는 유지한다.
- 모든 움직임은 기존 20초 시계로 계산한다. 정지·재개·스킵·재시작으로 별도 CSS/타이머가 흘러가지 않아야 한다.
- 전투 결과와 격자 이동 규칙은 유지한다. 음성·프레임 작화를 실제로 제작하지 않았다면 완료로 표시하지 않는다.

생성 원본과 프롬프트는 `web/source-art/sd-v3/`, 실제 로딩 자산은 `web/public/game/sd/`에 보존한다. 이전 v2 원화는 비교와 복구를 위해 남긴다.

## 전신 모션 보강

검격은 다리와 골반에서 출발해 몸통·팔·검끝 순서로 힘을 전달한다. 피격은 상체 반동, 뒤로 밀림, 무릎이 접히는 착지, 자세 회복으로 이어진다. 앞·뒷발 소켓으로 지면 높이와 그림자를 맞추며, 발의 실제 접지 지점에서 먼지를 발생시킨다.

잔광은 실제 검의 과거 위치를 같은 시계에서 계산한다. 충돌 파편은 충돌한 장소에 남기고, 피격자의 몸에서 발생하는 연기는 따로 움직인다. 따라서 효과를 보기 위해 기체를 멈추거나 서로 다른 타이머를 추가하지 않는다.

`/review`는 0.5배속/정속, 일시정지, 프레임 단위 이동과 임의 시간 탐색을 제공한다. 실제 게임과 동일한 렌더러를 사용하되 파일럿·HUD·음향 검사는 본편에서 수행한다. 구현·검사 결과는 [web/QA.md](../web/QA.md)에 기록한다.
