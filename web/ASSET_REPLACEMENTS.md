# SD 개편 소재 상태와 후속 제작

2026-10-16. 사용자의 SD 스프라이트·액션 표정·자연스러운 동작 요청을 반영한 v3. 원본 레퍼런스는 수정하지 않았습니다.

## 새로 제작해 실제 사용하는 것

| 소재 | 실제 파일 | 구현 상태 |
|---|---|---|
| 아스트레이온 SD 부품 16개 | `public/game/sd/hero/*.webp` | 머리·가슴·허리·등·양팔·양다리·라이플·실드·검 손잡이·핀, 투명 알파 |
| 옵시디언 SD 부품 16개 | `public/game/sd/rival/*.webp` | 같은 16파트 구조, 기체별로 측정한 별도 접합점. 흑색/진홍 장갑과 별도 얼굴·바인더 |
| 주인공 액션 컷인 | `public/game/sd/pilot-hero.webp` | 흰색/청색 헬멧, 조종간을 쥐고 외치는 전용 조종석 원화 |
| 라이벌 액션 컷인 | `public/game/sd/pilot-rival.webp` | 갈색 머리·반쪽 가면·조종간·공격 표정, 좌우 반전 없음 |
| 궤도 전장 | `public/game/sd/battlefield.webp` | 두 기체가 움직일 평탄한 외부 갑판, 우주/행성 배경 |
| 관절 동작 | `SDMechaRig.ts`, `rig-layout.ts`, `motion.ts` | 부품별 실제 회전축, 무장 들기·조준·반동·검격·피격·복귀. 손/무기/효과 좌표 연동 |
| 효과 | `BattleStage.ts` | 빔·추진·검광·타격·파편·잔연, 접촉 정지와 효과 감소 모드 |

내장 **image_gen**으로 원본 5장을 생성했습니다. 정확한 프롬프트와 원본은 `source-art/sd-v3/`에 보존합니다. `scripts/prepare-sd-art.mjs`는 투명 부품의 연결 영역을 분리하고 비례를 유지하여 최대256px WebP로 포장합니다. 원본에 그림을 덧그리는 처리나 가짜 알파 배경은 사용하지 않습니다.

첨부 게임 화면의 **큰 머리·짧은 다리·셀 채색 SD 래스터 스프라이트** 방향입니다. 손으로 매 프레임 새로 그린 애니메이션은 아니며, 분리한 실제 이미지 부품을 관절로 연결해 움직입니다.

## 교체되어 더 이상 전투에서 사용하지 않는 것

- v2의 풀 사이즈 기체8포즈 및 단일 충돌 그림. 파일은 비교·복구용으로 보존합니다.
- `public/game/animatic/pilot-*.webp`의 레퍼런스 크롭. 새 전용 원화로 교체했습니다.
- 이전 단순 SVG 기체는 `source-art/legacy-animatic/`에만 보관합니다.
- v2 궤도 배경은 전술 맵과 새 배경 로딩 실패 시 예비 배경으로만 남습니다.

## 아직 임시이거나 최종 제작이 필요한 것

1. **음악·효과음:** Web Audio로 합성한 데모 음향입니다. 최종 녹음·믹싱을 하지 않았습니다. 성우/TTS 음성 파일은 없습니다.
2. **파일럿 움직임:** 전용 액션 원화는 존재하지만 눈·입·표정 프레임 분리는 미제작입니다. 컷인 이동은 전투 시계에 동기화되어 정지/재개됩니다.
3. **기체 추가 작화:** 현재3/4시점 관절 동작을 넘어서는 뒤돌기·원근 변화·속도 잔상용 변형 원화와 접촉 전후 연결 작화가 필요합니다.
4. **디자인 검수:** 생성 부품의 표면 디테일과 장갑 정합성은 최종 모델 시트 승인을 대신하지 않습니다.

게임 상태와 피해는 `battle.ts`에 유지하며, 원화나 관절 보간에서 판정을 적용하지 않습니다. 기존 맵 도트 스프라이트는 직접 작성한 배열이며 실제 슈퍼로봇대전의 스프라이트·UI·음악을 복사하지 않았습니다.
