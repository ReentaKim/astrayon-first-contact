# 03 · 아트 기준과 자산 인계

## 현재 있는 것과 없는 것

현재 있는 것은 원본 설정화와 포스터 PNG 6장이다. 이들은 기체·인물·구도 참고 자료이며, 자막과 도해가 합쳐진 단일 이미지다. 배경이 제거된 스프라이트, 움직이는 영상, 신규 공격 컷, 별도 파일럿 표정, 녹음 음성은 아직 없다. 임시 크롭을 쓰더라도 '완성 애니메이션 컷'으로 표시하지 않는다.

## 디자인 기준 제안

| 요소 | 우선 참고 | 지킬 특징 |
|---|---|---|
| 아스트레이온 | 01, 02 | 백색 장갑·청색 몸통·금색 V핀·붉은 중앙부·청록 발광 센서 |
| 주인공 | 02 | 짙은 머리·젊은 인상·백색/청색 헬멧·투명 바이저 |
| 옵시디언 | 03, 04 | 흑색/진회색 장갑·진홍 발광·날카로운 실루엣·등쪽 바인더 |
| 라이벌 | **04의 큰 PILOT 초상** | 밝은 갈색 계열 머리·성숙한 얼굴선·비대칭 반쪽 가면·검정/적색 복장 |
| 장면의 분위기 | 05, 06 | 차가운 청색과 붉은 광원, 우주와 잔해, 과도하지 않은 실사 질감 |

라이벌은 03의 가면 없는 얼굴이나 06의 검은 머리 얼굴로 되돌리지 않는다. 가면은 얼굴에 착용한 별도 소품이다. 헬멧 바이저나 턱 보호대만으로 대체하지 않는다. 반대쪽을 향하는 새 컷에서도 가면이 덮는 해부학적 좌우는 동일해야 한다. 단순 이미지 좌우 반전은 그 조건을 깨뜨릴 수 있으므로 검사한다.

작화 제안은 선이 명확한 2D 애니메이션/셀 채색 계열이다. 장면마다 실사 3D, 수채화, 픽셀 표현을 섞지 않는다. 현재 설정화의 상세 기계 묘사는 식별 특징에 집중해 단순화할 수 있다. 디자인을 크게 바꾸는 것이 아니라 작은 화면에서도 형태가 읽히게 정리하는 작업이다.

자산 개수는 제작 범위 제안이다. 전부 새 이미지 호출을 하라는 지시가 아니라 필요한 자세·표정·레이어의 목록이다. 준비·돌진·피격 등의 핵심 동작이 보이는지 먼저 확인하고 불필요한 컷을 늘리지 않는다.

## 움직임 제작 기준

최종 연출은 레이어 패럴랙스, 준비·타격·반동 키포즈 전환, 효과 애니메이션을 조합한다. 짧은 영상이 추가되면 같은 장면의 다른 컷들과 기체 형태·무장·눈 색·가면을 비교 검수한 뒤 사용한다. 영상 생성 결과가 존재한다는 가정으로 코드 경로만 만들어놓지 않는다.

신규 원화에는 자막·수치·기관명·개봉일을 굽지 않는다. 텍스트는 코드 레이어에서 관리한다. `assets/references`는 원본 보존 위치로 두고, 실제 사용 자산은 `web/public/game/`에 최적화한 복사본을 둔다. 원본 6장을 전부 초기 로딩에 포함하지 않는다.

## 설정 데이터 주의

이미지 안의 E.F.S.F., GN Drive, 개봉일, 크레딧, 회사 이름, 수치, 표기 차이는 생성 당시의 장식적 설정을 포함한다. 사용자에게 확정된 세계관 정보로 보고하거나 자동 복제하지 않는다. 최초 구현은 기체명 ASTRAYON / OBSIDIAN과 임시 파일럿 호칭만 사용한다. 공식 건담 출시작처럼 소개하지 않는다. 공개 여부·표기·사용 자산의 정리는 별도의 배포 단계에서 결정한다.
