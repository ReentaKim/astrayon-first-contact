### 부품 접합 교정

- `rig-layout.ts`의 좌표는 셀 중앙값이 아니라 실제 분리 WebP의 관절 중심입니다. 앞·뒷팔과 두 기체가 각각 다른 좌표를 사용합니다.
- 가까운 팔·다리의 좌우, 목·몸통·골반 겹침, 팔꿈치·무릎, 라이플 손잡이 및 검 손잡이 부착점을 교정했습니다. 골반 회전에 몸통과 다리가 함께 움직입니다.
- 20초의 양 분기를 50ms 간격으로 검사했습니다. 원화상의 연결점은 목·허리·어깨·팔꿈치·손·고관절·무릎에서 오차 1e−6px 미만을 유지합니다. 가려진 허리·고관절의 원화 좌표는 장갑 내부에 위치하도록 추정한 값입니다.
- 실제 라이벌 배율 1.02에서 칼날과 목표 중심의 거리: 첫 패링 18.19px, 본 공격 18.73px, 반격 11.97px. 이는 논리 전장 1600×900 기준이며 장갑 면적 안에 접촉합니다.
- 손잡이 위치를 고정한 손목 조준으로 총신과 빔 방향을 맞췄습니다. 실제 빔 구간을 5ms 간격으로 별도 계산해 방향 일치를 확인했습니다.
- 시간 역행 탐색, 접촉 정지, 카메라 변환, 반격 후 피격 순서도 검사합니다. 수치 검사는 시각 검사를 대신하지 않습니다.

### 실제 실행에서 발견해 수정한 오류

맵 클릭 직후 첫 `requestAnimationFrame`의 시각이 클릭 때의 `performance.now()`보다 빠르면 경로 인덱스가 −1이 되어 이동 중 상태에 갇혔습니다. 경과 시간을 0 이상으로 제한하는 `sampleMovement`로 수정하고 음수 시간, 중간·경계 프레임, 완료·빈 경로 테스트를 추가했습니다. 최종 빌드에서 3칸과 5칸의 일반 이동을 다시 실행해 공격 화면까지 진입했습니다.

정적 서버의 `/review`는 같은 이름의 RSC 디렉터리를 먼저 발견해 존재하지 않는 `index.html`을 찾으며 404를 반환했습니다. 디렉터리에 index가 없으면 같은 이름의 `.html`을 찾도록 수정했습니다. 서버를 같은 주소로 재시작하고 `/review`에서 실제 13.50초 충돌 프레임이 표시되는 것을 확인했습니다.

## 실제 브라우저 플레이

프로덕션 `http://127.0.0.1:4173/`에서 확인했습니다.

- 맵 이동 → 무기 선택 → 파일럿 컷인 → 관절 공격 → 패링·충돌·반격 → 피해 → 결과 → 맵 복귀.
- 러시 **20.00초 자연 종료**: 아군 HP 5,600 / EN 100 / 적 HP 7,400. 파일럿 두 장, 준비·패링·본 공격·반격 프레임을 실제 재생 중 저장했습니다. `final-rush-frames.json`.
- 라이플 **20.00초 자연 종료**: 아군 HP 6,000 / EN 80 / 적 HP 7,800 / 조준 +1. 총구·빔·목표 연결과 피격 표시 확인. `final-rifle-check.json`.
- 컷인에서 일시정지한 뒤 1.5초 후에도 시간 **2.30초**와 컷인 transform/scale/stripe 값이 동일. 재개 후 정상 종료.
- 5열 4행에서는 라이플 활성·러시 비활성, 7열 4행에서는 라이플 비활성·러시 활성.
- 라이플 결과에서 맵 복귀 시 5열 4행 위치, HP 6,000, EN 80, 적 HP 7,800 유지.
- 재시작 후 5칸 일반 이동 → 러시 → 스킵에서도 HP 5,600 / EN 100 / 적 HP 7,400. `final-replay.json`.
- 수정 이후 검사 중 새 console warn/error 없음. `browser-console-history.json`의 한 건은 수정 전 `page-43227dcbbbc465e8.js`에서 발견한 위 이동 오류이며, 이를 삭제해 숨기지 않고 보존했습니다.

러시의 자연 재생 증거는 이동 오류 수정 직전에 찍은 최종 관절 빌드입니다. 이후 변경은 맵 보간 함수뿐이며 전투 렌더러·모션·원화는 동일합니다. 이동 수정 후에는 일반 맵 이동, 라이플 자연 재생, 러시 재시작·스킵을 다시 확인했습니다.

## 검증 범위와 남은 제작

- 개발 서버 `/review`의 자세 검수, 프로덕션 본편의 실제 플레이, 정적 서버 `/review`의 접촉 프레임을 확인했습니다. 처음 표시된 `ERR_BLOCKED_BY_CLIENT`와 별도로 서버 404를 진단해 위 경로 오류를 해결했습니다. 브라우저 보호 설정은 변경하지 않았습니다.
- 소리의 정지·재개 제어와 설정은 검증했지만 실제 스피커 청취, 음량 믹싱, 오디오 지연 측정은 하지 않았습니다. 성우 녹음은 없습니다.
- 이번 화면 검사는 데스크톱에서 수행했습니다. 이전 v2의 모바일 검사와 구분하며, 실제 모바일 GPU·터치, Safari/Firefox, 스크린리더, 장시간 성능은 이번 검사 범위에 포함하지 않습니다.
- 파일럿 눈·입 프레임, 기체의 다른 시점·원근 변화·연결 작화, 최종 음향은 후속 제작 대상입니다. 새 SD 부품은 실제 사용 소재이며 매 프레임 손으로 그린 완성 애니메이션과는 구분합니다. [ASSET_REPLACEMENTS.md](ASSET_REPLACEMENTS.md) 참조.
- 검수용 4180 개발 서버는 종료했습니다. 사용자 플레이용 **4173 서버는 실행 상태로 유지**합니다. 공개 배포는 하지 않았습니다.
